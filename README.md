# SkyDesk

Система для организации работы личного помощника руководителя (или супруги руководителя).

Не CRM и не «управление бизнесом» — фиксация поручений, помощь в исполнении, при необходимости финансирование и история.

Продукт рассчитан на использование как **PWA**: установка на телефон, быстрый вход с домашнего экрана, мобильный UI как основной сценарий.

## Зачем

Большинство задач приходит по телефону, в мессенджере или лично. Главный принцип — **максимальная скорость фиксации**: новое поручение за несколько секунд.

## Сущности

### Поручение (Task)

Главная сущность. Подзадача — то же поручение с `parent_id` (вложенность без лимита).

Может иметь:
- подзадачи
- несколько событий календаря (N↔N)
- несколько заявок на аванс
- дедлайн (отображается в календаре даже без события)

Закрытие родителя каскадно закрывает потомков. «Сделать основной» снимает `parent_id`.

### Событие (CalendarEvent)

Встреча, поездка, личное и т.д. Может существовать без поручений («едем загород») или быть связано с несколькими поручениями.

### Финансы

- **Общий кошелёк** — баланс «на руках»
- **Аванс** — заявка на деньги (в т.ч. на конкретную трату), опционально к поручению
- **Трата** — сумма + описание, к ней несколько фото-чеков
- Остаток → в кошелёк; можно обнулить как «неизвестное»; перерасход фиксируется в кошельке

### Словари (Настройки)

Статусы, приоритеты, типы поручений, типы событий — редактируются с цветом (и иконкой у типов задач).

## Жизненный цикл поручения

```
Получено поручение
  → создана задача (достаточно названия)
  → при необходимости: аванс / календарь / подзадачи
  → исполнение
  → при необходимости отчётные расходы
  → закрытие
```

## Рабочие экраны

1. **Вход** `/login`
2. **Главная** — сводка
3. **Поручения** — список + большая карточка
4. **Календарь** — FullCalendar + карточка события
5. **Финансы** — кошелёк и авансы
6. **Настройки** — профиль и словари

## Клиент (PWA)

- Мобильный интерфейс — приоритет: нижняя навигация, быстрое создание поручения (FAB / шторка)
- Светлая и тёмная темы, настраиваемый акцентный цвет
- Учёт safe-area для standalone-режима
- Офлайн и push — в планах (manifest, service worker)

## Стек

- Laravel 11 + Inertia.js
- Vue 3 + Vuetify 4
- FullCalendar
- MySQL (backend домена — в разработке)

## Статус

UI-прототип на клиентских моках (`localStorage`). Домен поручений / авансов на backend и PWA-установка — дальше.
