# SkyDesk

Система для организации работы личного помощника руководителя (или супруги руководителя).

Не CRM и не «управление бизнесом» — фиксация поручений, помощь в исполнении, при необходимости финансирование и история.

Продукт рассчитан на использование как **PWA**: установка на телефон, быстрый вход с домашнего экрана, мобильный UI как основной сценарий.

## Зачем

Большинство задач приходит по телефону, в мессенджере или лично. Главный принцип — **максимальная скорость фиксации**: новое поручение за несколько секунд.

## Сущности

### Поручение (Task)

Главная сущность. Подзадача — то же поручение с `parent_id` (вложенность без лимита).

Может иметь:
- подзадачи
- несколько событий календаря (N↔N)
- несколько заявок на аванс
- вложения (фото со сжатием на клиенте, документы)
- дедлайн (отображается в календаре даже без события)

Закрытие родителя каскадно закрывает потомков. «Сделать основной» снимает `parent_id`.

### Событие (CalendarEvent)

Встреча, поездка, личное и т.д. Может существовать без поручений или быть связано с несколькими поручениями.

### Финансы

- **На руках** = кошелёк + в авансах − неразнесённые расходы.
- **Кошелёк** — обычные приходы и расходы со счёта `wallet`.
- **Счёт аванса** — при статусе «деньги получены» сумма заявки зачисляется на аванс (не в кошелёк); способ выдачи — справочник.
- **Аванс** — заявка → получены → на отчёте (авто при первой связанной трате) → закрыта.
- **Расход** — сразу влияет на «на руках»; счёт списания: `wallet` / `advance` / `unassigned` (можно долго не разносить). Поставщик опционален; к расходу можно сразу прикрепить файл/фото.
- Перерасход по авансу списывает хвост с кошелька.
- К открытому авансу можно создать расход или прикрепить неразнесённый (со сменой счёта при необходимости); после закрытия открепить нельзя.
- Закрытие: остаток → перевод в кошелёк **или** списание без отчёта.
- Реестр движения: типы `income` / `expense` / `transfer`. UI: вкладки **Движение | Авансы**.
- Статьи расходов, способы выдачи и статусы авансов — в Настройках; поставщики — отдельная сущность (опционально с контактом).

### Словари (Настройки)

Статусы, приоритеты, типы поручений, типы событий — редактируются с цветом (и иконкой у типов задач).

## Стек

- Laravel 11 + Inertia.js (session auth)
- Vue 3 + Vuetify 4
- FullCalendar
- MySQL

## Быстрый старт

```bash
docker compose up -d
docker compose exec natassg-app composer install
docker compose exec natassg-app php artisan migrate --seed
docker compose exec natassg-app php artisan storage:link
npm install && npm run dev
```

# НИКОГДА НЕ ДЕЛАТЬ `migrate:fresh` / `db:wipe` / `migrate:refresh`

**НА РАБОЧЕЙ БД ЭТО ЗАПРЕЩЕНО.** Только `migrate` вперёд. Демо-данные — отдельно:

```bash
docker compose exec natassg-app php artisan demo:seed   # наполнить демо
docker compose exec natassg-app php artisan demo:clear  # убрать только демо (is_demo)
```

После сидера создаются пользователи `nkorsakov` и `nataliya` (полный email: `…@skydesk.local`). Пароль задаётся в сидере / окружении, в README не публикуется.

Сиды заполняют только словари и пользователей (с пустым кошельком). Поручения, события, авансы и контакты стартуют пустыми — пока не запущен `demo:seed`.

## Рабочие экраны

1. **Вход** `/login` (email/пароль; Telegram — если аккаунт привязан)
2. **Главная** — сводка
3. **Поручения** — список + большая карточка
4. **Календарь** — FullCalendar + карточка события
5. **Финансы** — кошелёк и авансы
6. **Контакты** — люди и организации
7. **Настройки** — профиль, пароль и словари
